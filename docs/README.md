# Repository Documentation and Reference Data

Human-facing repository documentation lives at the repository root:

- `README.md` is the operator guide.
- `ARCHITECTURE.md` defines pipeline boundaries.
- `SESSION.md` is the concise current-state checkpoint.
- `Legacy/SESSION_HISTORY.md` retains historical session detail.

Raw analysis workbooks and source-site exports do not belong in this directory
or in source control. Keep them in an approved external location and reference
their paths through run configuration when needed.
